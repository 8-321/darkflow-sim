## 3. 我们抽取的五条设计原则

1. **先给外壳，再给内容**：开机终端 → 地址栏 → 三栏工作台。用户先相信「这是一个不该存在的站」，才会读商品文案。
2. **每个动作都要有代价与延迟**：下单要托管、到货要等、验货可能翻车、赢拍会涨热度。没有延迟就没有紧张感。
3. **风险要可见**：风险点、热度条、卖家评分、涨跌幅全部前置，让「贪」变成主动选择而不是随机惩罚。
4. **两种输入并存**：鼠标点（大众）+ 终端命令（硬核）。终端不是装饰，`buy/crack/clean` 都能改状态。
5. **合规写进产品**：开机勾选、页脚「no network」、虚构地址点击提示、README 免责声明。题材敏感时，边界本身就是产品体验的一部分。

## 4. 未采用的方向（及原因）

- **真实 Tor / .onion 跳转**：违法风险与平台风险，且破坏「单机可分享」。
- **多人联机 / 服务端市场**：需要后端与审核，和「免费、私域、零运维」冲突。
- **真实支付/加密货币**：不接入，暗币只是游戏点数。
- **桌面窗口拖拽系统**（Aurora 路线）：移动端体验差、开发量大；改用视图切换 + 弹层。
