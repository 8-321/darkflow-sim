## 3. 本轮发现并修复的缺陷

| # | 现象 | 根因 | 修复 |
|---|---|---|---|
| 1 | 新档每秒弹「你被反超了」 | AI 每次抬价都 `emit('outbid')`，与玩家是否出价无关 | 仅在 `playerTop` 为真时退款+提示，其余走 `bid` |
| 2 | 移动端整页黑屏 | `emptyBox` 重复定义 → `SyntaxError`，模块未执行 | 删除重复定义；每次改动后 `node --check` 门禁 |
| 3 | 验货弹窗被事件弹窗顶掉 | 事件检查不判断当前是否已有弹窗 | 有弹窗时推迟事件；事件弹窗加 `.event` 标记 |
| 4 | 拍卖页每 0.8s 整页重绘，点击易被打断 | 用整页渲染刷新倒计时 | 改为 `updateAuctionClocks()` 原地更新，仅在出价/结算时重绘 |
| 5 | 375px 顶栏左右裁切、状态栏被导航盖住 | 品牌+地址+统计+按钮挤在一行 | 移动端改三行 grid，按钮移出统计区，隐藏状态栏 |
| 6 | 禁用的「压哨」仍像可点的亮绿按钮 | `.btn.primary` 填充色未被禁用态覆盖 | 禁用态透明底 + 暗色描边 |
| 7 | README 写的 `status` 命令不存在 | 文档先行、实现遗漏 | 新增 `status` / `orders` / `netstat` 并写入 `help` |
| 8 | 拍卖说明写「最后 3 秒」，实际 9 秒开放 | 文案与逻辑不一致 | 统一为 9 秒 |

## 4. 复现方式

```bash
cd 暗网游戏
python -m http.server 5173
# 浏览器打开 http://127.0.0.1:5173/
```

自动化脚手架在 `%LOCALAPPDATA%\hermes\cache\scratch\`：`df-cdp.mjs`（单步）、`df-shots.mjs`（多视图）、`df-bid.mjs`（出价）、`df-snipe2.mjs`（压哨）、`df-375.mjs`（移动端+结局）。需要本机 9555 端口的无头 Edge。
